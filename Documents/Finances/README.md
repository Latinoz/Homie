# Модуль учёта финансов (Finances)

## Обзор

Модуль **Finances** — это комплексная система управления личными финансами и инвестиционным портфелем. Система предназначена для учёта различных классов активов с автоматическим обновлением котировок из внешних источников.

## Основные возможности

- **Мультивалютный учёт** — поддержка RUB, USD, EUR, CNY, GBP и других валют
- **Автоматическое обновление цен** — интеграция с ЦБ РФ, MOEX, Yahoo Finance, CoinGecko
- **Учёт инфляции** — расчёт реальной стоимости портфеля с учётом ИПЦ
- **Журнал операций** — полная история всех финансовых транзакций
- **Дашборд** — сводная информация, графики распределения активов и динамики капитала

## Поддерживаемые классы активов

| Класс актива | Описание | Источник цен |
|--------------|----------|--------------|
| **Банковские вклады** | Депозиты с учётом процентов и капитализации | Ручной ввод |
| **Инвестиции** | Акции, облигации, ETF на брокерских счетах | MOEX, Yahoo Finance |
| **Криптовалюта** | Криптоактивы на биржах и в кошельках | CoinGecko |
| **Драгоценные металлы** | Золото, серебро, платина, палладий | ЦБ РФ |

## Быстрый старт

1. **Настройте валюты** — добавьте необходимые валюты в справочник
2. **Создайте счета** — добавьте банки, брокеров, кошельки или криптобиржи
3. **Добавьте активы** — создайте вклады, инвестиционные позиции или криптоактивы
4. **Ведите журнал операций** — фиксируйте все транзакции для точного учёта
5. **Используйте дашборд** — отслеживайте состояние портфеля в реальном времени

## Технологии

- **ASP.NET Core MVC** — веб-фреймворк
- **Entity Framework Core** — ORM для работы с базой данных
- **IHttpClientFactory** — HTTP-клиенты для внешних API
- **Chart.js** — визуализация графиков на дашборде
- **Background Services** — фоновое обновление котировок
- **SmartBreadcrumbs** — навигационные хлебные крошки
