# Руководство пользователя

## Введение

Модуль «Учёт финансов» предназначен для комплексного управления личными финансами и инвестиционным портфелем. Система позволяет вести учёт различных классов активов: банковские вклады, инвестиции в ценные бумаги, криптовалюты и драгоценные металлы.

---

## Начало работы

### Шаг 1: Настройка справочников

Перед началом работы рекомендуется настроить базовые справочники.

#### 1.1 Валюты

Перейдите в **Finances → Currencies** и убедитесь, что добавлены необходимые валюты:

| Код | Название | Код ЦБ |
|-----|----------|--------|
| RUB | Российский рубль | — |
| USD | Доллар США | R01235 |
| EUR | Евро | R01239 |

#### 1.2 Банки и брокеры

Добавьте организации, с которыми вы работаете:

- **Finances → Banks** — банки (Сбербанк, Тинькофф, ВТБ...)
- **Finances → Brokers** — брокеры (Тинькофф Инвестиции, БКС, Финам...)
- **Finances → CryptoExchanges** — криптобиржи (Binance, Bybit, OKX...)
- **Finances → Wallets** — криптокошельки (MetaMask, Trust Wallet...)

#### 1.3 Типы операций

Перейдите в **Finances → OperationTypes** для просмотра и настройки типов операций.

Предустановленные типы:
- Пополнение вклада / Снятие со вклада
- Начисление процентов
- Покупка / Продажа ценных бумаг
- Получение дивидендов / купонов
- Покупка / Продажа криптовалюты
- Покупка / Продажа драгметалла

---

### Шаг 2: Создание счетов

Перейдите в **Finances → Accounts** и создайте счета для каждого места хранения активов.

#### Пример: Банковский счёт

1. Нажмите **«Создать»**
2. Заполните форму:
   - **Название:** Сбербанк — основной счёт
   - **Тип:** Банк
   - **Банк:** Сбербанк (выберите из списка)
   - **Валюта:** RUB
   - **Активен:** ✓
3. Нажмите **«Сохранить»**

#### Пример: Брокерский счёт

1. Нажмите **«Создать»**
2. Заполните форму:
   - **Название:** Тинькофф Инвестиции — ИИС
   - **Тип:** Брокер
   - **Брокер:** Тинькофф Инвестиции
   - **Валюта:** RUB
3. Нажмите **«Сохранить»**

## Учёт банковских вкладов

### Добавление вклада

1. Перейдите в **Finances → Deposits**
2. Нажмите **«Создать»**
3. Заполните форму:
   - **Название:** Накопительный счёт 2024
   - **Счёт:** Сбербанк — основной счёт
   - **Валюта:** RUB
   - **Сумма:** 500000
   - **Процентная ставка:** 16.5
   - **Дата открытия:** 01.01.2024
   - **Дата закрытия:** 01.01.2025 (если срочный)
   - **Капитализация:** ✓ (если проценты капитализируются)
4. Нажмите **«Сохранить»**

### Учёт операций по вкладу

Для точного расчёта баланса фиксируйте все операции:

#### Пополнение вклада

1. Перейдите в **Finances → Operations**
2. Нажмите **«Создать»**
3. Заполните:
   - **Дата:** 15.03.2024
   - **Тип операции:** Пополнение вклада
   - **Счёт:** Сбербанк — основной счёт
   - **Сумма:** 100000
   - **Валюта:** RUB

#### Начисление процентов

1. **Тип операции:** Начисление процентов
2. **Сумма:** (начисленные проценты)

### Просмотр баланса

На странице **Deposits → Details** отображается:
- Начальная сумма
- Текущий баланс (из журнала операций)
- Начисленные проценты
- Стоимость в рублях

## Учёт инвестиций

### Добавление инструмента

Перед добавлением позиции убедитесь, что инструмент есть в справочнике.

1. Перейдите в **Finances → Instruments**
2. Нажмите **«Создать»**
3. Заполните:
   - **Код:** SBER
   - **Название:** Сбербанк
   - **Тип:** Акция
   - **Биржа:** MOEX
   - **Валюта:** RUB
4. Нажмите **«Сохранить»**

### Добавление позиции

1. Перейдите в **Finances → Investments**
2. Нажмите **«Создать»**
3. Заполните:
   - **Инструмент:** SBER — Сбербанк
   - **Счёт:** Тинькофф Инвестиции — ИИС
   - **Количество:** 100
   - **Средняя цена покупки:** 250.00
   - **Автообновление цены:** ✓
4. Нажмите **«Сохранить»**

### Учёт сделок

#### Покупка акций

1. **Finances → Operations → Создать**
2. Заполните:
   - **Дата:** 01.02.2024
   - **Тип:** Покупка ценных бумаг
   - **Счёт:** Тинькофф Инвестиции — ИИС
   - **Инструмент:** SBER
   - **Количество:** 50
   - **Цена:** 245.00
   - **Валюта:** RUB
   - **Комиссия:** 12.25 (0.1% от суммы)

#### Получение дивидендов

1. **Тип:** Получение дивидендов
2. **Инструмент:** SBER
3. **Сумма:** 1500.00 (после вычета налога)
4. **Налог:** 230.00 (если известен)

### Метрики позиции

На странице **Investments → Details** отображается:
- Количество (из журнала)
- Средняя цена покупки
- Текущая цена
- Доходность (%)
- Полученные дивиденды
- Стоимость в рублях

## Дашборд

### Просмотр сводки

Перейдите в **Finances → Dashboard** для просмотра:

1. **Общий капитал** — сумма всех активов в рублях
2. **Распределение по классам:**
   - Банковские вклады
   - Инвестиции
   - Криптовалюта
   - Драгоценные металлы
3. **Доходность** — общая доходность портфеля
4. **Реальная стоимость** — с учётом инфляции
5. **Графики:**
   - Круговая диаграмма распределения активов
   - Линейный график динамики капитала

### Обновление котировок

1. Нажмите кнопку **«Обновить котировки»**
2. Дождитесь завершения (может занять 30-60 секунд)
3. Проверьте результат обновления

Котировки также обновляются автоматически:
- Курсы ЦБ — ежедневно в 11:30 МСК
- Котировки — ежедневно в 22:00 МСК

### Добавление данных

1. Перейдите в **Finances → Inflation**
2. Добавьте месячные данные ИПЦ:
   - **Год:** 2024
   - **Месяц:** Январь

### Влияние на расчёты

- Дашборд показывает **реальную стоимость** портфеля с учётом накопленной инфляции
- Формула: `Реальная стоимость = Номинальная стоимость / (1 + Накопленная инфляция)`

## Советы по использованию

### 1. Регулярно фиксируйте операции

Точность расчётов зависит от полноты журнала операций. Фиксируйте:
- Все покупки и продажи
- Пополнения и снятия
- Дивиденды, купоны, проценты
- Комиссии и налоги

### 2. Используйте автообновление цен

Включите автообновление для инструментов с поддержкой API:
- MOEX: российские акции и облигации
- Yahoo Finance: международные акции
- CoinGecko: криптовалюты
- ЦБ РФ: драгметаллы

### 3. Проверяйте курсы валют

Убедитесь, что курсы валют актуальны для корректного пересчёта в рубли.

### 4. Ведите учёт инфляции

Добавляйте месячные данные ИПЦ для расчёта реальной доходности.

### 5. Используйте категории счетов

Разделяйте активы по типам счетов:
- Банковские счета — для вкладов
- Брокерские счета — для инвестиций
- Кошельки — для долгосрочного хранения криптовалюты
- Биржи — для активной торговли криптовалютой

## Часто задаваемые вопросы

### Как добавить новую валюту?

**Finances → Currencies → Создать**

Укажите код валюты и код ЦБ РФ для автоматического получения курса.

### Почему не обновляется цена инструмента?

Проверьте:
1. Включено ли автообновление (**IsAutoUpdateEnabled = true**)
2. Нет ли блокировки после ручного ввода (24 часа)
3. Корректность тикера/CoinGecko ID
4. Доступность внешнего API

### Как рассчитывается доходность?

```
Доходность (%) = (Текущая цена - Средняя цена покупки) / Средняя цена покупки × 100
```

Дивиденды и купоны учитываются отдельно.

### Как учесть налоги?

При добавлении операции заполните поле **«Налог»**. Сумма будет учтена в расчётах.

### Как перенести активы между счетами?

1. Создайте операцию **«Перевод между счетами»** (или две операции: снятие + пополнение)
2. Укажите исходный и целевой счета
